# DouK 全流程一体化管理器

面向 Windows X64 的便携式自用管理程序，统一管理：

- DouK 账号采集器本机服务；
- `settings_master.json` 与任务版 `settings.json`；
- `A1,A10-A99,A879` 形式的账号选择；
- 固定数量或自定义范围的批次任务；
- DouK-Downloader 下载引擎调用；
- 账号截图安全归档；
- 视频账号文件夹快捷方式索引；刷新和独立清理都会按类别显示发现、计划、删除、失败与剩余数量；
- 启动前、修改前和下载前只备份 3 个关键文件并自动限制保留数量；下载引擎更新前完整备份 Volume；
- 管理器日志和下载任务日志。
- 下载引擎 ZIP 只读预检、安全更新和旧引擎程序永久留存；更新时移动保留唯一正式 Volume。

## v0.1.4 队列、监听和结果追溯

下载队列支持模板全选/取消全选、鼠标左键拖动选中或取消整段后批量删除，删除范围严格限定为
`Data/Tasks/*.json`；任务页提供打开任务目录和日志目录入口。新增后台剪贴板监听按钮：
监听使用 `run_command=6`，批量账号下载使用现有 `5 1 1 Q`，停止监听或启动时发现残留会安全恢复；
监听启动不重复生成正式设置备份，管理器启动时的关键文件备份继续作为统一安全快照。

“下载结果”页从现有 `DownloadTask_*.log` 读取账号状态，筛选会自动刷新，双击来源日志可直接打开；账号任务创建页可按最近 N 天
（默认 3 天、可改为 7/15 等）预览并智能跳过明确私密账号，支持强制包含全部。队列暂停只暂停
队列推进，不影响当前下载；完成后关机默认关闭，只有结果可靠且采集服务未启用时才提供 60 秒可取消的
Windows 正常关机倒计时。

“取消全部下载任务”会停止当前由管理器启动的批量下载并清空本次待执行模板，不删除模板、日志、
`settings.json` 或数据库；结果查看在任务运行期间动态生效，未勾选时不会出现结束后按键提示。

下载器退出码 `0` 只代表进程正常结束。账号可能因接口错误、私密状态、没有新作品
或防重复记录而没有产生下载结果，管理器不会把进程正常退出误报为账号下载成功。

## v0.1.3 下载账号结果汇总

每个下载进程结束后，管理器会在启动下一项队列任务前逐行分析本次下载器原生日志，
分别显示进程退出状态与账号结果。汇总包含计划及实际开始账号数、各主状态数量，
以及私密、异常、中断、未开始和异常后完成账号的完整 A 编号；证据不足时会明确标记
“结果不完整”或“无法可靠汇总”。原生日志保留在下载器原路径，不复制、不修改；
除既有 `DownloadTask_*.log` 追加汇总外，不生成独立缓存或结果文件。六类已开始账号
主状态互斥且合计等于实际开始数；“完成但有异常记录”是可与主状态重叠的附加状态，
明确不计入主状态合计。

## 任务模板怎样复用

- `F:\DouK-Manager\Data\Tasks\*.json` 是永久保留、可反复使用的完整任务模板；
- 下载器不会直接读取 `Data\Tasks`，它始终只读取唯一正式
  `_internal\Volume\settings.json`；
- “将勾选任务设为正式 settings.json”会先备份 3 个关键文件，再把一个模板复制为正式文件；
- “按顺序运行勾选任务”会逐个执行“备份 → 激活为正式 settings.json → 启动下载”；
- 队列列表完全关闭拖放；高亮任务后可移到最前、上移、下移、最后或指定第 N 位；
- 高亮任务时可使用 `Alt+↑` / `Alt+↓` 快速上移或下移；
- 人工顺序保存在 `Data\task_order.json`，不修改模板内容；新模板仍按首个 A 编号插入人工槽位；
- “恢复按 A 编号排序”只在用户主动点击时清除人工槽位；
- “运行当前正式 settings.json”不使用任务列表，直接运行当时已经激活的正式文件；
- 下载结束后的黑框可以选择保留以查看统计，也可以在无人值守队列中选择自动关闭；结果查看会影响后续队列和关机倒计时，
  相关选项支持在任务运行期间动态生效。
- 每启动一次下载器进程生成一份 `DownloadTask` 日志；日志明确记录任务模板、
  实际启用且 URL 有效的账号数、每多少账号暂停一次及暂停秒数。

## 重要安全原则

1. 唯一正式数据始终位于下载引擎的 `_internal\Volume`。
2. `settings_master.json` 的 `enable` 不会因任务选择而改变。
3. 任务选择只在任务版 `settings.json` 中设置 `enable`。
4. 只有用户明确勾选时，才会把所选账号的 `earliest` 写回主档。
5. 所有正式 JSON 使用“临时文件 + 校验 + 原子替换”。
6. 修改正式数据或启动批量下载前必须先完成关键文件备份；后台监听沿用管理器启动时的关键快照，不重复备份；完整 Volume 备份只在手动确认或更新引擎前执行。
7. 更新下载引擎时禁止覆盖 `_internal\Volume`。
8. 本仓库禁止提交数据库、主档、任务配置、Cookie、截图、日志和备份。
9. 旧采集器 Excel 只补齐尾部缺失账号；既有行即使链接写法不同也原样保留。
10. 同名任务模板自动递增编号，不覆盖旧模板。
11. 索引功能只读取视频账号源目录；删除仅限快捷方式索引目录顶层带 `[DoukIndex]` 标记的 `.lnk`。

## 默认正式路径

```text
下载引擎：F:\DouK-Downloader_Custom_50_150\DouK-Downloader_Windows_X64_20260626\main.exe
视频目录：F:\DouK-Downloader
索引目录：F:\Douk videos
运行目录：F:\DouK-Manager
```

所有路径都可以在管理器设置页面修改。正式 `Volume` 路径由下载引擎路径推导，不能单独指向另一份主档。

## 账号表达式示例

```text
A1,A10-A99,A879
1,10-99,879
A1，A10-A99，A879
A1-A250
```

编号按 `accounts_urls` 的数组位置固定映射，不会因为空 URL 而重新编号。

## 本地源码运行

需要 Python 3.12：

```powershell
python -m pip install -e .
python main.py
```

运行自动测试：

```powershell
python -m unittest discover -s tests -v
```

## Windows 便携版构建

仓库包含 `.github/workflows/build-windows.yml`。上传到 GitHub 后：

1. 打开仓库 `Actions`；
2. 选择“构建 Windows 便携版”；
3. 点击 `Run workflow`；
4. 构建完成后下载 `DouK-Manager_Windows_X64` Artifact；
5. 解压到 `F:\DouK-Manager`；
6. 双击 `DouKManager.exe`。

编译产物、运行数据和正式账号资料都不会写入源码仓库。

## v0.1.0 稳定版

v0.1.0 已完成 Windows 实机闭环验收，覆盖账号采集、任务生成与队列、下载引擎调用、截图归档、索引刷新与受管快捷方式清理。

最终验收包括：

1. 两种“每批完成 / 整个队列完成”后处理组合；
2. `earliest` 仅任务生效及按需写回主档，并确认主档 `enable` 不变；
3. 单下载进程保护、重复启动拦截及异常退出后停止剩余队列；
4. 三个关键文件的副本恢复、哈希、JSON解析和SQLite检查；
5. 隔离索引中空源目录快捷方式、目标不存在快捷方式及正常快捷方式的正向删除边界。

管理器会通过环境变量向兼容版下载引擎传入“每批账号数 / 暂停秒数”。未包含兼容补丁的原版引擎会忽略这些变量并按自身内置规则运行。兼容版下载引擎仍可直接双击；未收到管理器参数时默认使用 `50/150`。

详细范围和已知边界见 [FEATURES-v0.1.0.md](FEATURES-v0.1.0.md) 与 [RELEASE-NOTES-v0.1.0.md](RELEASE-NOTES-v0.1.0.md)。
