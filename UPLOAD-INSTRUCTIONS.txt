DouK Manager 索引数字汇总与中文日志修复

基线：用户上传的最新 DouK-Manager-main 源码（归档标识 3acf4c004365dc5bbb3e6b897473b3ad9ec85a34）

使用方法：
1. 保持本覆盖包内的相对目录不变，覆盖仓库中的同名文件。
2. resources/scripts 下两份正式脚本必须与 Python 源码一起上传，不能只替换脚本。
3. 提交后等待 GitHub Actions 全部通过，再下载新 EXE。

本次规则：
- F:\DouK-Downloader 只扫描、统计和提示，管理器不会删除其中任何内容。
- 唯一允许删除的位置是 F:\Douk videos 顶层带 [DoukIndex] 标记的 .lnk。
- 空源文件夹、目标已移动或删除的文件夹、计划删除、实际删除、失败和剩余均分开显示具体数字。
- 删除“源文件夹删除数固定为 0”字段。
- 脚本控制台、运行日志、管理器日志和结果框均显示中文。
- 刷新本身会自动清理；“再次扫描并重试清理”用于独立维护或重试失败项。

回归结果：52 项测试中 47 项通过，5 项因当前环境缺少 Windows 桌面/PySide6 条件而按预期跳过。
