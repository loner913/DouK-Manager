## 主题与偏好保存

管理器启动后，进入左侧“设置”，在“外观”区域选择主题：

- **跟随系统**：使用 Windows 当前应用配色，并响应系统配色变化。系统无法报告配色时显示浅色，选择仍保持“跟随系统”。新 UI 配置默认使用此项。
- **浅色／深色**：固定使用所选配色，不随系统变化。

选择后立即应用并保存，无需点击正式路径的保存按钮。右上角太阳／月亮按钮会切换为当前外观的相反主题，同时改为固定浅色或深色；要恢复自动跟随，请在设置中重新选择“跟随系统”。

主题偏好保存在窗口使用的 UI 配置中，键为 `ui/theme/strategy`，不会写入正式账号、观察记录或下载配置。正常重启会恢复主题选择；这不表示未提交的表单输入也会跨重启保存。运行中切换主题不重建页面、不启动或停止任务。

若显示“主题已应用，但偏好保存失败”，当前外观已经切换，但重启后可能无法保留。处理 UI 配置目录的写入问题后重新选择主题；不要将此提示当作账号或任务写入失败。旧配置没有主题键或键值无效时按“跟随系统”处理。

相较旧版，本版新增自动跟随与主题选择持久化。真实 Windows 配色变化、显示缩放及逐页外观仍需独立前台验收。
