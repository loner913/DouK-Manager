# V0.1.3 Download Result Summary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在每个 TikTokDownloader 进程结束后可靠定位并逐行分析本次原生日志，将账号级结果写入管理器信息框及现有 `DownloadTask_*.log`，并在汇总结束前阻止队列启动下一任务。

**Architecture:** 新增一个不依赖 GUI 的 `download_summary` 核心模块，负责冻结计划账号、内存日志快照、候选日志定位、逐行账号状态机、统计校验和文本格式化。`EngineService` 在启动前建立不可变运行上下文，进程结束后调用汇总服务；GUI 使用独立 `QThread` 执行汇总并在完成回调后推进队列。原生日志保持原位，除既有任务日志外不生成任何结果或缓存文件。

**Tech Stack:** Python 3.12+、标准库 `dataclasses`/`enum`/`pathlib`/`re`、PySide6 `QObject`/`QThread`、`unittest`、Windows X64 便携构建。

- [ ] **Step 3: Implement immutable mapping and snapshot types**

Add these public definitions to `download_summary.py`, keeping URL values out of retained models:

```python
@dataclass(frozen=True)
class PlannedAccount:
    task_index: int
    a_number: int
    mark: str


@dataclass(frozen=True)
class NativeLogState:
    path: Path
    size: int
    mtime_ns: int


class SummaryInputError(ValueError):
    pass


def freeze_planned_accounts(document: dict) -> tuple[PlannedAccount, ...]:
    accounts = document.get("accounts_urls")
    if not isinstance(accounts, list):
        raise SummaryInputError("settings.json 缺少 accounts_urls 数组。")
    planned: list[PlannedAccount] = []
    for position, raw in enumerate(accounts, start=1):
        if not isinstance(raw, dict):
            raise SummaryInputError(f"settings.json 的 A{position} 不是对象。")
        url = str(raw.get("url", "")).strip()
        if not raw.get("enable", True) or not url:
            continue
        mark = str(raw.get("mark", "")).strip()
        if re.match(rf"^A{position}(?!\d)", mark, re.IGNORECASE) is None:
            raise SummaryInputError(f"settings.json 的 A{position} mark 与数组位置不一致。")
        planned.append(PlannedAccount(len(planned) + 1, position, mark))
    if not planned:
        raise SummaryInputError("settings.json 没有启用且 URL 有效的账号。")
    return tuple(planned)


def snapshot_native_logs(log_dir: Path) -> tuple[NativeLogState, ...]:
    if not log_dir.is_dir():
        return ()
    states = []
    for path in sorted(log_dir.glob("*.log"), key=lambda item: item.name.casefold()):
        try:
            stat = path.stat()
        except OSError:
            continue
        states.append(NativeLogState(path.resolve(), stat.st_size, stat.st_mtime_ns))
    return tuple(states)
```

@dataclass(frozen=True)
class NativeLogSegment:
    path: Path
    offset: int
    length: int


@dataclass(frozen=True)
class LocatedNativeLogs:
    segments: tuple[NativeLogSegment, ...]

Implement discovery rules:

1. Build a dictionary of `before` states by resolved, case-folded Windows path.
2. Stat current `.log` files after process exit.
3. Candidate is new, or current size is greater than its old size.
4. New file segment starts at byte `0`; grown file starts at old byte size.
5. Ignore unchanged files and files whose final `mtime` is earlier than `started_at - 2 seconds`.
6. If exactly one candidate exists, return it as reliable.
7. If zero or more than one exist, return no segments and an explicit unreliable reason.

Do not create a file, touch mtimes, or read file contents in this discovery step.
