## 四项功能的关系

四项功能共享同一条“证据先于动作”的边界，但职责彼此独立：

1. **mark 归类**把冻结任务中的账号 mark 作为主身份映射，只接受能证明为同一值的单向别名，防止日志文本被猜测性归类。
2. **引擎回退**只替换下载引擎程序文件，把正式 `Volume` 留在原位置，并在移动和校验失败时恢复程序与数据边界。
3. **账号健康审计**汇总任务结果和可选的精确原生日志证据，区分身份风险、可达性和隐私状态；用户确认后只改变主档 `enable`，不改变账号数组结构。
4. **日志统计与诊断**只读取可靠的日志区间，聚合固定白名单字段，生成诊断前执行全量脱敏自检；结果看板为当前和历史任务提供只读选择与缓存结果。

四项功能不是互相替代的判定器：日志统计不会把请求失败推断为封禁，账号审计不会用缺失日志猜测健康状态，mark 归类也不会把模糊文本变成身份事实。
