- 27 英寸显示器；

- Windows 缩放 100%；
- `system`、`light`、`dark` 三种主题策略；
- 多缩放实机矩阵按 `V017-DEC-004` 取消，不作为发布门禁。

`v017-runtime/handoffs/current.md` 当前引用的不可覆盖 checkpoint 为准。

## 延后优化

### V017-OPT-SEARCH-001：顶部搜索能力与占位文案不一致

- 类型：非阻塞优化；
- 状态：`DEFERRED_LATER_VERSION`；
- 当前行为：顶部搜索只按页面或功能名称进行导航；
- 当前文案：占位提示包含账号、任务、页面和功能，范围大于实际能力；
- V0.1.7 决定：保持现有实现，不扩大本次发布范围；
- 后续可选方案：实现账号/任务搜索，或把占位提示收窄为页面/功能导航；
- 后续验收：文案必须与实际可搜索对象一致，且不得改变正式账号、任务或下载状态。

该项不影响现有页面导航，也不影响总览、任务、下载、观察名单或版本身份数据，因此不阻塞 v0.1.7。
